# 🎨 Data Visualization — IPL 2025
### CodeAlpha Data Analytics Internship — Task 3

## 📌 Objective
Transform IPL 2025 batting data into professional
visual charts using Matplotlib and Seaborn.

## 🛠️ Tools & Libraries
Python | Matplotlib | Seaborn | Pandas | NumPy

## 📁 Files
- `Task3_Visualization.py` — All charts code
- `charts/` — 10 saved PNG chart images

## ▶️ How to Run
pip install pandas matplotlib seaborn numpy
python Task3_Visualization.py
